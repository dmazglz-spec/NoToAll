# WPF Accounting Application Template 📊🎮

Полнофункциональный шаблон WPF приложения для бухгалтера с современным игровым интерфейсом.

## 🎯 Описание

Это готовый к использованию шаблон WPF приложения, специально разработанный для бухгалтеров. Интерфейс вдохновлен игровым дизайном с яркими цветами, анимациями и удобной навигацией.

## 🎮 Компоненты интерфейса

### 🔝 Верхняя панель инструментов
- **Логотип** - "ACCOUNTING PRO" с современным дизайном
- **Основные кнопки**:
  - 📄 Новый отчет
  - 📂 Открыть
  - 💾 Сохранить
  - 🔄 Обновить
- **Поле поиска** - быстрый поиск по отчетам
- **Статус подключения** - информация о состоянии сервера

### 📊 Центральная область - Таблица отчетов
Excel-подобная таблица с колонками:
- **ID** - уникальный номер отчета
- **Тип отчета** - категория (Приход, Расход, НДС и т.д.)
- **Описание** - полное описание отчета
- **Дата** - дата создания/изменения
- **Сумма** - денежные суммы (выделены цветом)
- **Статус** - статус выполнения (✓ Завершен, ⏳ В процессе)

Чередующиеся цвета строк облегчают чтение данных.

### 📋 Правая сворачиваемая панель
**Функции:**
- Список доступных отчетов (4 типа)
- Каждый отчет содержит:
  - Название отчета
  - Описание
  - Progress bar с процентом выполнения
- Кнопка "−" для сворачивания (280px → 60px)
- Кнопка "➕ Добавить отчет"

**Сворачивание:**
```
Развернуто: 280px ↔ Свернуто: 60px
```

## 🚀 Как использовать

### Требования
- **Visual Studio 2022** или новее
- **.NET 6.0 SDK** или выше
- **WPF Desktop Development Tools**

### Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/dmazglz-spec/NoToAll.git
   cd NoToAll/WPFAccountingApp
   ```

2. **Откройте проект в Visual Studio**:
   ```bash
   start WPFAccountingApp.csproj
   ```

3. **Соберите решение**:
   ```
   Ctrl + Shift + B
   ```

4. **Запустите приложение**:
   ```
   F5 или Ctrl + F5
   ```

## 🎯 Функциональные возможности

### Основные действия
- ✅ **Новый отчет** - создание нового отчета
- ✅ **Открыть** - загрузка существующего отчета
- ✅ **Сохранить** - сохранение текущего отчета
- ✅ **Обновить** - обновление данных из сервера
- ✅ **Поиск** - поиск отчетов по названию
- ✅ **Сворачивание панели** - переключение между развернутым (280px) и свернутым (60px) состоянием

### Визуальные эффекты
- 🎮 Наведение на кнопку - смена цвета (синий → голубой)
- 🎮 Закругленные углы и неоновые границы
- 🎮 Progress bars для отслеживания выполнения
- 🎮 Чередующиеся цвета строк таблицы

## 💡 Расширение функциональности

### Добавление новых отчетов
Отредактируйте раздел **Reports List** в `MainWindow.xaml`:

```xaml
<!-- Report N -->
<Border Background="#0F1419" BorderBrush="#00D4FF" BorderThickness="2" CornerRadius="6" Padding="10">
    <StackPanel Spacing="5">
        <TextBlock Text="Название отчета" Foreground="#FF6B35" FontWeight="Bold" FontSize="12"/>
        <TextBlock Text="Описание" Foreground="#FFFFFF" FontSize="11" TextWrapping="Wrap"/>
        <ProgressBar Value="50" Background="#004E89" Foreground="#00D4FF" Height="6" CornerRadius="3"/>
        <TextBlock Text="Выполнение: 50%" Foreground="#00D4FF" FontSize="10"/>
    </StackPanel>
</Border>
```
